## 重點（依 lesson）

### §1.9 字面值與運算子
- 字面值是直接寫在原始碼裡的固定值；字面值和變數都有值和型別，字面值的值不能改。
- 運算（operation）取 0 個以上的輸入值（運算元，operand），產生一個新值；代表運算的符號叫運算子（operator）。
- 運算子依運算元數量分為一元（例如負號 `-x`）、二元（例如 `+`）等。
- 算術運算的順序和數學相同：先括號，再乘除，再加減。`2 + 3 * 4` 是 14。
- 除了算出值之外，還有其他可觀察效果的，叫副作用（side effect），例如 `x = 5` 改變了 x、`std::cout << 5` 印出東西。

### §1.10 運算式
- 運算式（expression）是由字面值、變數、運算子、函式呼叫組成的序列，會算出一個值；算的過程叫求值（evaluation）。
- 運算式本身沒有分號，必須放在敘述裡面。
- 運算式加上分號，叫運算式敘述（expression statement），例如 `x = 5;`。
- 對照：
  - 想讓程式「做一件事」用敘述，想「算出一個值」用運算式。
  - `x = 5;` 是運算式敘述；`int x = 5;` 是包含運算式的敘述；`int x;` 是沒有運算式的敘述。
- 凡是需要單一值的地方，都可以放一個會算出值的運算式。

### §6.1 優先順序與結合性
- 優先順序（precedence）高的運算子先和它的運算元結合：`4 + 2 * 3` 是 `4 + (2 * 3)`。
- 同一優先順序時，看結合性（associativity）：`7 - 4 - 1` 是 `(7 - 4) - 1`。
- 括號可以明確指定運算順序，例如 `(4 + 2) * 3`。
- 原站建議：
  - 不簡單的複合運算式要加括號，讓意圖一目了然。
  - 經驗法則：除了加減乘除，其他都加括號。
- C++ 沒有次方運算子；`^` 是位元 XOR（範圍外）。

### §6.2 算術運算子
- 一元：`+x`、`-x`。二元：`+`、`-`、`*`、`/`、`%`。
- 只要有一邊是浮點數，`/` 就做浮點數除法、保留小數：`7.0 / 4` 是 1.75。
- **兩邊都是整數**時做整數除法，小數直接丟掉：`7 / 4` 是 1、`-7 / 4` 是 -1。
- 想讓兩個整數相除保留小數：用 `static_cast<double>(x) / y`。
- 整數除以 0 是未定義行為（程式很可能當掉）。
- 複合賦值：`+=`、`-=`、`*=`、`/=`、`%=`，例如 `x += 4;` 等於 `x = x + 4;`。

### §6.3 餘數與次方
- `%` 取整數除法的餘數：`7 % 4` 是 3；只能用在整數上。
- 最常用來檢查能不能整除：`x % y` 等於 0 代表 x 可以被 y 整除。
- 除數比被除數大時，餘數就是被除數：`2 % 4` 是 2。
- 有負數時，結果的正負號跟著左邊：`-6 % 4` 是 -2。
- 原站建議：盡量拿 `%` 的結果和 0 比較。用 `(x % 2) == 1` 判斷奇數，遇到負數會出錯。
- C++ 沒有次方運算子；`^` 不是次方。算次方要 `#include <cmath>` 再用 `std::pow()`。

### §6.4 遞增／遞減與副作用
- `++x`（前置遞增）、`--x`、`x++`（後置遞增）、`x--`。
- 單獨成為一個敘述時，`++x;` 和 `x++;` 效果相同；差別只在放進更大的運算式時才會出現。
- 原站建議：優先使用前置版本（`++x`），因為效能較好、比較不會出乎意料。
- 警告：同一個敘述裡，不要對同一個變數使用超過一次帶有副作用的運算，結果可能是未定義的。

### §6.7 比較運算子
- `>`、`<`、`>=`、`<=`、`==`（相等）、`!=`（不相等），結果都是 `bool`（`true` / `false`）。
- 原站建議：不要多寫 `== true`。`if (b1 == true)` 直接寫成 `if (b1)`。
- 浮點數比較很危險：
  - `100.0 - 99.99` 和 `10.0 - 9.99` 理論上都是 0.01，實際比較卻不相等。
  - `0.3 == 0.2 + 0.1` 的結果是 false。
- 原站警告：浮點數只要可能是算出來的，就避免用 `==` 和 `!=` 比較。

### §6.8 邏輯運算子
- `!`（NOT）：反轉布林值。`&&`（AND）：兩邊都 true 才 true。`||`（OR）：任一邊 true 就 true。
- 可以串接，例如 `value > 10 && value < 20 && value != 16`。
- `!` 的優先順序很高：`!x > y` 會變成 `(!x) > y`；想否定整個比較，要寫 `!(x > y)`。
- `&&` 的優先順序比 `||` 高。原站建議：混用時，每一組都加括號。
- 短路求值：`&&` 左邊是 false、`||` 左邊是 true 時，右邊不會被計算。
- 原站警告：`value == 0 || 1` 是錯的，條件永遠成立；要寫 `value == 0 || value == 1`。
- 不要把 `&&`、`||` 和位元運算子 `&`、`|` 搞混。
