## 重點（依 lesson）

### §4.10 if 敘述入門
- if 敘述讓一段程式只在條件（condition）成立時執行；條件是會算出布林值的運算式。
- 條件是 true 就執行，false 就跳過。
- `if (條件) 敘述1; else 敘述2;`：兩者**剛好執行其中一個**。
- 可以用 `else if` 串接任意多個條件。
- 條件不是布林值時會被轉換：非 0 是 true，0 是 false。
- 警告：if 只會控制**一個**敘述；要控制多個敘述必須用區塊（見 8.2）。

### §7.1 複合敘述（區塊）
- 區塊（block）是一組敘述，編譯器把它當成「一個敘述」來看待；用 `{` 開始、`}` 結束，`}` 後面不用分號。
- 最常見的用法：搭配 if，讓條件成立時執行多個敘述。
- 區塊可以巢狀（區塊裡面還有區塊）。
- 原站建議：函式的巢狀層數保持在 3 層以內。

### §8.1 控制流程
- 程式預設從 `main` 的開頭依序執行到結尾；每次都執行相同敘述的程式叫「直線程式」。
- 控制流程敘述會改變執行路徑；跳到不是下一行的敘述叫分支（branching）。
- 類別：條件敘述（if、else、switch）、跳躍（break、continue…）、迴圈（while、do-while、for…）等。
- 原站說：控制流程，尤其是迴圈，讓程式能做真正有用的事。

### §8.2 if 敘述與區塊
- 沒有區塊時，if 或 else 只控制**一個**敘述，**不管縮排怎麼排**。原站例子：「Too bad!」對每個輸入都會印出。
- 要控制多個敘述，就用區塊包起來。
- 沒寫區塊時，編譯器會自動加上隱含的區塊；所以在 if／else 裡直接宣告的變數，離開那個分支就不存在了。
- 單一敘述要不要加大括號有爭議；原站列的加括號理由：
  - 避免不小心加了一行，看起來屬於 if，其實不是。
  - 除錯比較方便。
- 原站說社群似乎比較傾向一律加。
- 原站建議：**學習期間，單一敘述也放進區塊**。
- 只想執行「第一個成立的條件」用 if-else；想執行「所有成立的條件」用一串獨立的 if。

### §8.3 if 敘述的常見問題
- if 可以巢狀。
- else 會配對**同一個區塊裡、最近一個還沒配對的 if**（dangling else）；把內層的 if 用區塊包起來就不會混淆。
- 巢狀的 if 常常可以改寫：重新安排邏輯，或用邏輯運算子攤平，比較不容易出錯。
- 空敘述（null statement）只有一個分號，什麼都不做。
- **在 if 條件後面多加分號**：if 就控制那個空敘述，後面原本想條件執行的敘述變成**一定會執行**，即使它在區塊裡。
- **在條件裡用 `=` 而不是 `==`**：`if (x = 0)` 會把 0 賦值給 x，條件變成 false，所以程式永遠印出 "You entered 1"。
