## 重點（依 lesson）

### §4.1 基本資料型別
- 所有資料在記憶體裡都是一串位元（0 和 1）；型別告訴編譯器要怎麼解讀這些位元。
- 程式設計者的工作是：依照用途挑選適合的型別。
- 基本型別包括：
  - 浮點數：`float`、`double`、`long double`。
  - `bool`。
  - 字元型別：`char` 等。
  - 整數型別：`short`、`int`、`long`、`long long`。
  - 以及 `void` 等。
- 字串不是基本型別，而是標準函式庫的一部分（5.7，範圍外）。

### §4.4 有號整數
- 整數可以存正數、負數和 0。
- `int` 在現代電腦上通常是 32 位元，範圍 -2,147,483,648 到 2,147,483,647。
- 超出範圍叫溢位（overflow）；有號整數溢位是未定義行為（範圍外，不展開）。
- **整數除法的結果一定是整數，小數部分直接丟掉、不四捨五入**：`8 / 5` 是 1，`-8 / 5` 是 -1。

### §4.8 浮點數
- 浮點數變數用來存有小數的數字，例如 4320.0、-3.33。
- 常用 `double`。原站建議：除非很在意空間，否則用 `double`，不要用 `float`（精確度不足）。
- 沒有字尾的小數字面值（例如 `5.0`）型別是 `double`；有小數點就是浮點數，即使小數部分是 0。
- `std::cout` 不會印出為 0 的小數部分：`5.0` 會印成 `5`。很大的數可能用科學記號印出，例如 `9.87654e+06`。
- `std::cout` 預設顯示 6 位有效數字。
- 捨入誤差：有些數字（例如 0.1）沒辦法被精確存成二進位；誤差會在重複計算中累積。原站提醒：**永遠不要假設浮點數是精確的**。
- 原站建議：字面值的型別要和變數的型別一致。

### §4.9 布林值
- `bool` 變數只有兩個值：`true` 和 `false`。
- 布林值其實存成整數：`true` 是 1、`false` 是 0。
- `std::cout` 預設印出 `1` / `0`；輸出 `std::boolalpha` 之後會印出 `true` / `false`。
- `!`（邏輯 NOT）會把布林值反過來。
- 原站說，布林值是你會用得最多的型別。

### §4.11 字元
- `char` 存一個字元（字母、數字、符號或空白）；字元字面值放在**單引號**裡，例如 `'g'`、`'1'`、`' '`。
- `char` 其實存的是整數（ASCII 碼），例如 `'a'` 是 97；`std::cout` 印 `char` 時會印出字元，不是數字。
- 不要把字元的數字和整數搞混：`'5'` 是字元，存的是 ASCII 碼 53，不是整數 5。
- 單引號是 `char` 字面值，雙引號是文字（字串）字面值；單一字元原則上用單引號。
- 跳脫序列以反斜線開頭，例如 `\n`（換行）、`\t`（tab）。

### §4.12 型別轉換與 static_cast
- 編譯器自動進行的型別轉換叫隱式轉換；`double` 轉成 `int` 會丟掉小數部分。
- 型別轉換不會改變原本的變數，而是產生一個新的值。
- 用 `static_cast<新型別>(運算式)` 明確地要求轉換；程式設計者自己為這個轉換負責。
- 大括號初始化會擋下不安全的隱式轉換（`int x { 5.5 };` 編譯錯誤），這是原站推薦大括號的主要理由之一。
