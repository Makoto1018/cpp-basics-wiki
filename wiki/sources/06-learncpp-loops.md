## 重點（依 lesson）

### §8.8 迴圈與 while
- 迴圈（loop）讓一段程式重複執行，直到某個條件達成。
- 動機：要印 1 到 10，一行一行寫還可以；但如果次數要到執行時才知道（例如使用者輸入的數字），就做不到了。
- `while (條件) 敘述`：
  - 每次都先檢查條件。true 就執行主體，然後回到開頭再檢查一次；false 就結束。
  - 和 if 不同，主體可以執行很多次。
- 一開始條件就是 false 時，主體一次都不執行。
- 無窮迴圈：條件永遠成立。原站的例子是忘了 `++count`，結果不停地印出 `1`。
- 故意寫的無窮迴圈用 `while (true)`，可以用 return、break 等方式離開。原站建議用 `while (true)` 來寫故意的無窮迴圈。
- 警告：while 條件後面多一個分號，主體就變成空敘述，迴圈什麼都不做、永遠不結束，程式看起來像當掉。
- 控制迴圈次數的變數叫迴圈變數（loop variable），最常見的是計數器（counter）。
- 迴圈變數常被命名為 `i`、`j`、`k`，但這些名字很難搜尋；可以用 `count`、`index` 這種名字。
- 主體每執行一次叫一輪（iteration）；可以用 `%` 讓某件事每 N 輪做一次。
- 原站建議：整數迴圈變數用有號型別（例如 `int`）。
- 巢狀迴圈：迴圈裡面還有迴圈。

### §8.9 do-while（延伸閱讀，範圍外）
- `do 敘述 while (條件);`：先執行一次，再檢查條件，所以主體至少執行一次。
- 原站說實務上不常用；選擇相當時，優先用 while。

### §8.10 for
- for 是 C++ 最常用的迴圈。有明顯的迴圈變數時優先使用，因為定義、初始化、檢查、更新都集中在同一行。
- 語法：`for (初始化敘述; 條件; 結束運算式) 敘述`。
- 執行順序：
  1. 初始化敘述（只執行一次）
  2. 條件（false 就結束）
  3. 主體
  4. 結束運算式
  5. 回到第 2 步
- 等價的 while 寫法：初始化放在迴圈前面，結束運算式放在主體最後一行，外面再包一層區塊；迴圈變數在迴圈結束後就不存在了。
- 初始化敘述裡定義的變數，只在迴圈裡面有效（loop scope）。
- 變化寫法：用 `--i` 倒數、用 `i += 2` 一次加 2。
- 原站建議：數值條件用 `<` 或 `<=`，不要用 `!=`（變數可能跳過終點，造成無窮迴圈）。
- 差一錯誤（off-by-one）：迴圈多跑或少跑一次。例如想印 1 到 5，卻寫成 `i < 5`，結果只印 `1 2 3 4`。
- `for (;;)` 等於 `while (true)`，但原站建議用 `while (true)`。
- 巢狀 for：外層每跑一輪，內層就完整跑完一次。
- 原站建議：只在迴圈裡用的變數，就定義在迴圈裡。
- 結論：有計數器時用 for，沒有時用 while。

### §8.11 break 與 continue
- `break`：
  - 結束 while、do-while、for（和 switch），從迴圈後面的下一個敘述繼續執行。
  - 常用來離開故意寫的 `while (true)`。
  - 原站例子：讓使用者輸入最多 10 個數字，輸入 0 就停止，最後印出總和。
- `break` 和 `return` 不同：break 只結束迴圈，return 結束整個函式。
- `continue`：
  - 結束**這一輪**，不是結束整個迴圈；直接跳到迴圈主體的最後面。
  - 在 for 裡，continue 之後**結束運算式（例如 `++count`）仍然會執行**。
  - 在 while 裡，continue 可能跳過更新條件變數的那一行。原站例子：count 到 5 之後就不再遞增，印出 0 到 4 後永遠不結束。
- 很多教科書反對用 break／continue，因為流程會跳來跳去；但適當使用可以減少巢狀和多餘的布林變數。
- 原站建議：break 和 continue 能讓迴圈邏輯更簡單時就用。
